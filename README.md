# Falcon Elite Track Club

Website for Falcon Elite, a Maryland youth track & field club.

- Live site: https://falcon-elite.github.io/website/
- Instagram: https://www.instagram.com/falcon_elite_track/
- Facebook: https://www.facebook.com/profile.php?id=100090351171654

## Editing
Everything is in `index.html`. Settings near the bottom of the file:
- `FORM_ENDPOINT` - paste a Formspree link to turn on the contact form
- `INSTAGRAM_POSTS` / `PHOTOS` - add posts or photos to the Follow the Flock section
